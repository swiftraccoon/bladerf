# bladeRF documentation catalog tools

A host-only Rust CLI for the [canonical catalog](../../docs/knowledge/catalog.json)
and its [schema](../../docs/knowledge/catalog.schema.json). It checks structural
and selected semantic consistency, then reproduces the committed
[fact reference](../../docs/handbook/fact-catalog.md). It uses the shared Rust
toolchain and lockfile, with no radio SDK or native SDR dependency.

Run from the workspace root:

```sh
cargo run --locked -p bladerf-docs -- check
cargo run --locked -p bladerf-docs -- render --check
```

After deliberately changing and source-checking the catalog:

```sh
cargo run --locked -p bladerf-docs -- render
```

`render` atomically replaces `docs/handbook/fact-catalog.md`. `render --check`
compares exact generated bytes and fails on drift without writing. `--catalog`,
`--schema`, and `--output` accept alternate paths; missing parent directories are
reported rather than created. Existing schema/catalog paths cannot be used as
the output. The tool does not fetch citations or inspect a connected radio.

The checker rejects duplicate JSON object keys at every depth, unknown schema
fields, duplicate record IDs, missing references, incompatible source/locator
kinds, out-of-document PDF pages,
reversed ranges, and floating-point JSON representations in integer facts.
Conflicted claims need an open source-disagreement issue with at least two
declared sources. Input JSON files are limited to 2 MiB each; drift comparison
reads at most the expected output length plus one byte.

Source hashes, identities and locators remain declarations requiring source
review. Passing checks does not verify remote bytes, confirm a cited symbol's
meaning, establish a board rating, or validate an equipment configuration.
`jsonschema` HTTP/file retrieval features are disabled, and external `$ref` and
`$dynamicRef` targets are rejected. Schema files are trusted repository inputs;
this is not a general adversarial-schema service.

Use the [handbook build guide](../../docs/BUILDING.md) to render the complete
handbook after checking the catalog.
